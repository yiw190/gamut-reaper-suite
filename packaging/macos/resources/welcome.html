Hibiki

Lets AI agents drive REAPER and puts a chat panel inside it. Installs, for the logged-in user:

  • the REAPER MCP server and its Lua bridge, started with REAPER
  • the Hibiki panel (and ReaImGui if it's missing)
  • the agent gateway for Gamut, Codex, Claude Code and other ACP agents

The MCP is registered in Gamut, Claude Desktop, Claude Code and Cursor when they're installed. Everything listens on 127.0.0.1 only. REAPER must already be installed.
