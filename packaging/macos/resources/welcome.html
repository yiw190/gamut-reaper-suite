Hibiki

Step 1 — REAPER. Hibiki runs inside REAPER. If it isn't on this Mac yet, download it from reaper.fm, drag it to Applications and open it once. This installer won't continue without it.

Step 2 — Hibiki. Installs, for the logged-in user:

  • the REAPER MCP server and its Lua bridge, started with REAPER
  • the Hibiki panel (and ReaImGui if it's missing)
  • the agent gateway for Gamut, Codex, Claude Code and other ACP agents

The MCP is registered in Gamut, Claude Desktop, Claude Code and Cursor when they're installed. Everything listens on 127.0.0.1 only.
