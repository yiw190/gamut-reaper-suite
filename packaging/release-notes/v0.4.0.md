First packaged release: install the whole suite on a Mac that has REAPER with one `.pkg`.

**Install:** download `GamutReaperSuite-0.4.0.pkg`, open it, restart REAPER, then run `gamut-reaper-suite doctor`.
The package isn't signed yet. If macOS won't open it, go to System Settings → Privacy & Security → **Open Anyway**.

### What's in it
- **REAPER MCP server.** 14 grouped tools (`status`, `transport`, `track`, `midi`, `fx`, `send`, `item`, `envelope`,
  `project`, `render`, `action`, `reaper_call`, `run_lua`, `batch`) and the Lua bridge (0.4.0). The bridge starts with
  REAPER from a marked block in `Scripts/__startup.lua`.
- **Gamut Chat panel.** A ReaImGui panel docked in REAPER that talks to Gamut agents and ACP agents and attaches REAPER
  context to each message. ReaImGui 0.10.0.5 is installed if missing.
- **Agent gateway.** It listens on `127.0.0.1:47892`. `gamut-reaper-suite agents add codex claude kimi` adds those
  agents.
- **Bundled Python 3.12.** No Xcode command line tools needed.
- **`gamut-reaper-suite` CLI.** `setup`, `doctor`, `connect`, `agents`, `watchdog`, `uninstall`.
- **Client registration.** The MCP gets registered in Gamut, Claude Desktop, Claude Code and Cursor when they're
  installed.

### Upgrading from a clone install
`setup` replaces the hand-made `com.yitian.reaper-mcp` and `com.yitian.reaper-watchdog` LaunchAgents and adopts a
copied startup hook. It also keeps the existing bearer from `~/.config/reaper-mcp/env`, so registered clients keep
working. The watchdog stays on if it was on.

### Changed
- `python/` and `lua/` are gone. The server, HTTP front and bridge all live in `reaper_mcp/`, and MCP configs point at
  `reaper_mcp/server.py`.
- The HTTP front reads its bearer from `~/.config/reaper-mcp/token`, so the plist no longer holds it.
- `gateway/install_macos.sh` → `gamut-reaper-suite agents add`. `scripts/install-watchdog.sh` →
  `gamut-reaper-suite watchdog on`.
