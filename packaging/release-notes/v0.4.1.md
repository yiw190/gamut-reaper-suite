First release of **Hibiki** (響, "resonance"): AI agents inside REAPER — an MCP server that drives REAPER, a chat
panel docked in REAPER, and a gateway for Gamut, Codex, Claude Code and Kimi. One `.pkg` installs it all.

### Install
1. **REAPER first.** Download it from [reaper.fm](https://www.reaper.fm/download.php), drag it to Applications and open
   it once. The installer won't continue without it.
2. **Hibiki.** Download `Hibiki-0.4.1.pkg` below and open it. It isn't signed yet: if macOS won't open it, go to
   System Settings → Privacy & Security → **Open Anyway**.
3. **Restart REAPER.** The Hibiki panel opens docked on the right. Check everything with `hibiki doctor`.

### What's in it
- **REAPER MCP server.** 14 grouped tools (`status`, `transport`, `track`, `midi`, `fx`, `send`, `item`, `envelope`,
  `project`, `render`, `action`, `reaper_call`, `run_lua`, `batch`) and the Lua bridge (0.4.1), started with REAPER
  from a marked block in `Scripts/__startup.lua`.
- **Hibiki panel.** A ReaImGui panel styled like REAPER's own track panel. The header shows the agent and model in
  effect; clicking it opens **Agent settings**, a Routing-style window for provider (Gamut, Codex, Claude Code, Kimi),
  Gamut agent, model / effort / mode and the context switch. For Claude Code and Kimi, **Open in …** reopens the chat
  in the agent's own CLI in Terminal. ReaImGui 0.10.0.5 is installed if missing.
- **REAPER context.** Every message carries the project, tempo, cursor with nearby markers, and each selection kind —
  time selection, razor areas, tracks, items, MIDI notes, envelope, FX — with how long ago it was set, so the agent
  can tell what you just touched from leftover selections. Time and razor ranges list their chord markers and what
  plays there. Pills above the input show the same selections.
- **Agent gateway** on `127.0.0.1:47892`. `hibiki agents add codex claude kimi` adds those agents.
- **Bundled Python 3.12.** No Xcode command line tools needed.
- **`hibiki` CLI.** `setup`, `doctor`, `connect`, `agents`, `watchdog`, `uninstall`.
- **Client registration.** The MCP gets registered in Gamut, Claude Desktop, Claude Code and Cursor when they're
  installed.

### Upgrading from an earlier install
`setup` replaces the old LaunchAgents (`com.yitian.*`, and `com.gamut-reaper-suite.*` from before the rename) with
`com.hibiki.*`, swaps a hand-copied startup hook for the managed block, removes the old `Scripts/GamutChat` panel,
and keeps the existing bearer, so registered clients keep working. The panel carries its saved state (agent, chats,
model picks) over from its old name. The watchdog stays on if it was on. Close the old panel before upgrading.

### Changed
- `python/` and `lua/` are gone: the server, HTTP front and bridge live in `reaper_mcp/`; MCP configs point at
  `reaper_mcp/server.py`.
- The HTTP front reads its bearer from `~/.config/reaper-mcp/token`, so the plist no longer holds it.
- `gateway/install_macos.sh` → `hibiki agents add`; `scripts/install-watchdog.sh` → `hibiki watchdog on`.
