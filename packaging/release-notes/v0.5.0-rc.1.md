**Release candidate: Windows support.** Hibiki now installs on Windows as well as macOS. Everything below passed CI
on Windows Server, but nobody has run it on a desktop REAPER for Windows yet — that's what this RC is for. Please
report what breaks.

### Install
1. **REAPER first** — [reaper.fm](https://www.reaper.fm/download.php). Both installers refuse to continue without it.
2. **Hibiki** — macOS: `Hibiki-0.5.0-rc.1.pkg`. Windows (10 1803+, 64-bit): `Hibiki-0.5.0-rc.1-setup.exe`, a per-user
   install with no administrator rights. Neither is signed yet: macOS → Privacy & Security → **Open Anyway**;
   Windows SmartScreen → **More info → Run anyway**.
3. **Restart REAPER.** The panel opens docked on the right; click the agent name at its top for settings.
   `hibiki doctor` checks everything.

### New: Windows
- **Panel.** Background requests through Windows' own `curl.exe` and `ExecProcess` (no console windows), Microsoft
  YaHei UI / Consolas fonts, **Open in Claude Code / Kimi** in a `cmd` window.
- **Services.** One windowless supervisor keeps the MCP (`127.0.0.1:8787`) and the agent gateway (`127.0.0.1:47892`)
  running, restarts either when it exits, and starts at logon (HKCU Run). Logs: `%LOCALAPPDATA%\Hibiki\logs`.
- **Installer.** Bundled Python 3.12, `hibiki` on PATH, upgrades in place (stops the services first), uninstalls from
  Settings → Apps. REAPER's resource path is `%APPDATA%\REAPER`.
- Not on Windows yet: the REAPER watchdog (macOS only).

### Fixed (both platforms)
- **The panel couldn't start on a Mac without ReaPack.** Setup now also installs ReaImGui's `imgui.lua` shim
  (sha256-checked). It isn't a ReaImGui release file, so v0.4.1 never installed it.
- **Chinese text sent from the panel could arrive garbled** where the C runtime treats some bytes ≥ 0x80 as control
  characters (Windows); the JSON encoder now escapes by explicit byte range.

### Upgrading
From v0.4.1 (macOS), install the new package over it. Setups from before the rename are migrated as described in the
v0.4.1 notes.
