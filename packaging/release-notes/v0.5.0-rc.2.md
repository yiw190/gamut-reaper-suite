**Release candidate 2: onboarding without a terminal.** Everything from rc.1 (Windows support) plus: a new user can go
from "installed" to "talking to an agent" inside the Hibiki panel.

### Install
1. **REAPER first** — [reaper.fm](https://www.reaper.fm/download.php). Both installers refuse to continue without it.
2. **Hibiki** — macOS: `Hibiki-0.5.0-rc.2.pkg`; Windows (10 1803+, 64-bit): `Hibiki-0.5.0-rc.2-setup.exe` (per user, no
   admin rights). Not signed yet: macOS → Privacy & Security → **Open Anyway**; Windows SmartScreen → **More info → Run
   anyway**.
3. **Restart REAPER** — the panel opens docked on the right.
4. **Connect an agent** — right in the panel (below).

### New
- **"Connect an agent" card** when no agent is chosen: one **Install** button per CLI agent, and **Download Gamut**
  (official link for your OS; Gamut needs Docker Desktop, OrbStack or Podman and an Anthropic API key, no sign-up).
- **One-click CLI agents**: Claude Code, Codex, Kimi, and new **MiniMax** (global or mainland login) and **Grok**
  (Grok Build, browser sign-in; SuperGrok / X Premium+ beta). Install puts Node and the CLI in `~/.local/node`, no admin
  rights, and loads the agent without restarting anything; then **Connect** logs in once. Also in **Agent settings →
  Provider**.
- **Enable REAPER for a Gamut agent**: Gamut gives MCP servers to agents one by one; the panel now shows
  **Enable REAPER for <agent>** until the chosen agent has it. Terminal: `hibiki connect gamut --agent "<name>"`
  (or `--all-agents`, or pick from a list).
- Not one-click yet: Qwen Code (API key through environment variables only) and DeepSeek (automation-only ACP server).

### Fixed since rc.1
- Panel helpers moved into scoped blocks to stay under Lua's 200-local limit (the new features had hit it).

### Upgrading
Install the new package over rc.1 or v0.4.1.
