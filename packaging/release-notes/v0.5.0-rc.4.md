**Release candidate 4: more agents and an MCP-only install.** Everything from rc.3 plus Gemini CLI and GitHub
Copilot CLI as one-click agents, and `hibiki setup --mcp-only` for people who only want the MCP.

### Install
1. **REAPER first** — [reaper.fm](https://www.reaper.fm/download.php). Both installers refuse to continue without it.
2. **Hibiki** — macOS: `Hibiki-0.5.0-rc.4.pkg`; Windows (10 1803+, 64-bit): `Hibiki-0.5.0-rc.4-setup.exe` (per user, no
   admin rights). Not signed yet: macOS → Privacy & Security → **Open Anyway**; Windows SmartScreen → **More info → Run
   anyway**.
3. **Restart REAPER** — the panel opens docked on the right.

Only want the MCP for Claude Desktop, Claude Code or Cursor? Skip the package and see **MCP only** below.

### New
- **Gemini** (`@google/gemini-cli` 0.65.0): Google sign-in in the browser; uses your Google AI Pro / Ultra plan. The
  panel shows only the Google login; Gemini's API-key, Vertex AI and gateway methods are hidden (a new optional
  `authMethods` list per agent).
- **Copilot** (`@github/copilot` 1.0.103): `copilot login` (device code) in Terminal; uses your Copilot Pro / Pro+
  subscription. Runs with `--no-auto-update` so the pinned version stays.
- Both install from the panel (**Install**, then **Connect**) or with `hibiki agents add gemini copilot`, at pinned
  versions with install scripts off.
- **MCP only**: `sh install.sh --mcp-only` from a clone (Windows: `python -m reaper_mcp setup --mcp-only`) installs the
  bridge and a startup hook that starts only the bridge, and registers the stdio MCP in Claude Desktop, Claude Code
  and Cursor. No panel, ReaImGui, gateway, token, LaunchAgents or autostart. Gamut needs the full setup (it connects
  over the HTTP service). `hibiki doctor --mcp-only` checks just those pieces.
- Panel: scripted demo typing for screen recordings (ExtState `demo_agent` / `demo_new` / `demo_type`).

### Docs
- README: demo video, "Just want the MCP?" link, Gemini and Copilot in the agent table; the panel doesn't need Gamut.
- `SECURITY.md`, `CONTRIBUTING.md` and a bug report template that asks for `hibiki doctor` output.
