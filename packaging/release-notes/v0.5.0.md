**Hibiki 0.5.0: Windows, agents set up from the panel, a security and speed pass, and REAPER tools that check their own work.** This is the first stable release since v0.4.1 and includes everything from rc.1–rc.4, plus the tool fixes below.

### Install
1. **REAPER first**: [reaper.fm](https://www.reaper.fm/download.php). Both installers refuse to continue without it.
2. **Hibiki**:
   - macOS: `Hibiki-0.5.0.pkg`.
   - Windows (10 1803+, 64-bit): `Hibiki-0.5.0-setup.exe`. It installs per user and needs no admin rights.
   - Neither installer is signed yet. On macOS go to Privacy & Security and choose **Open Anyway**. On Windows, at the SmartScreen prompt choose **More info**, then **Run anyway**.
3. **Restart REAPER.** The panel opens docked on the right. Pick an agent in it, or click **Install** next to a CLI agent.

Only need the MCP for Claude Desktop, Claude Code or Cursor? Use `sh install.sh --mcp-only` from a clone.

### Highlights since v0.4.1
- **Windows support**:
  - A per-user installer that bundles Python.
  - One windowless supervisor runs the MCP service and the agent gateway, and starts them at logon.
  - The panel runs on Windows too.
  - (rc.1)
- **Connect an agent from the panel**:
  - One-click installs at pinned versions: Claude Code, Codex, Kimi, MiniMax, Grok, Gemini and Copilot.
  - **Download Gamut** links to the Gamut app.
  - **Enable REAPER for \<agent\>** gives a Gamut agent access to REAPER.
  - (rc.2, rc.4)
- **Security and speed pass**:
  - The macOS installer's root step no longer writes into your home folder.
  - The MCP service needs a bearer of at least 32 characters.
  - The gateway checks Origin, Host and the token before it reads the request body.
  - Supply chain: ACP adapters, cloudflared and CI actions are pinned to fixed versions.
  - The panel lays out streaming replies incrementally and skips messages that are off screen.
  - Bridge JSON is about 2× faster.
  - ACP agents that sit idle are stopped.
  - (rc.3)
- **`hibiki recover`** and the panel's **Recover** button restart the MCP and the gateway without touching REAPER. (rc.3)
- **`hibiki setup --mcp-only`** installs just the bridge and the stdio MCP. (rc.4)

### New in 0.5.0: tools that check their own work
We audited 3,508 REAPER tool calls from real agent sessions. Agents fell back to `run_lua` 1,501 times to do things the tools should handle. This release fixes that without adding or removing any tool: the set is still 14, and every new parameter is optional.

- **`render`**:
  - Brings media online first.
  - Refuses to write over an existing file, so REAPER's overwrite prompt can no longer block the bridge.
  - Refuses while any track is soloed and names those tracks. To solo or mute tracks for a single render, pass `solo_indices` or `mute_indices`; they are restored afterwards. `allow_solo` overrides the check.
  - Returns each file's path, size, length, peak and LUFS-I.
  - Warns when a file is silent or wasn't written, when the master is muted, and when stems come out as the master.
- **`fx set formatted=`** sets a parameter by the value the plugin displays, for example `-18`, `4` (for 4:1) or `3.2k`. It returns the value that was actually set.
- **`send`** takes `mode`, `src_channel` and `dst_channel` (`2` = channels 3/4) for kick sidechains.
- **`envelope`**: `unit=db` writes in dB. Inactive envelopes are switched back on.
- **`status`** reports `any_solo`, `master_mute` and `dirty`.
- **`run_lua`** takes an optional `timeout`. Errors now show the failing source line and say not to resend.

### Not yet
- Signing and notarization of the macOS package and Windows installer. This needs an Apple Developer ID and a Windows code-signing certificate.
- `render stems=true` can still produce the master instead of the stems. The result now flags it; until it's fixed, use `solo_indices` renders.
- Gemini and Copilot logins have been tested at the ACP level, but not yet end to end with real accounts.

### Upgrading
Install the new package over any 0.5.0 RC or over v0.4.1. If your bearer is shorter than 32 characters it is replaced on upgrade (see the rc.3 notes). Once the new package is installed, `hibiki doctor` should report bridge `0.5.0`.
