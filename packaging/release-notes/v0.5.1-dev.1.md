**Dev build for testing — not a stable release.** Use it only if you're testing these changes; otherwise stay on [v0.5.0](https://github.com/yiw190/hibiki/releases/tag/v0.5.0).

### Install
Install the package over v0.5.0, the same way you'd install a normal release. Once it's done, `hibiki doctor` should show `0.5.1-dev.1`.

### New
- **`hibiki stop` / `hibiki start`**:
  - `stop` turns off the MCP service, the agent gateway, the watchdog and, if it's installed, the Cloudflare tunnel. They stay off after the next login, until you run `start` or `setup`.
  - REAPER keeps running, and so does its bridge, which simply has nothing to talk to.
  - `stop` also ends any ACP agents that were left over.
  - `start` brings back exactly what was running before the stop. For example, if the watchdog was off before `stop`, it stays off.
  - While stopped, `hibiki doctor` reports the services as "stopped", not as failures. `hibiki recover` and the panel's Recover button won't start them again; they tell you to run `hibiki start`.
  - Windows: `stop` ends the supervisor and removes the logon autostart; `start` puts both back.

### Changed
- **No console window when REAPER starts.** The bridge no longer prints "ready" to the ReaScript console, which used to open that window on every launch. Errors still appear there. Set `REAPER_MCP_DEBUG=1` to see the startup line again.
