**Dev build for testing — not a stable release.** It includes everything in [0.5.1-dev.1](https://github.com/yiw190/hibiki/releases/tag/v0.5.1-dev.1) (`hibiki stop` / `start`, and no console window when REAPER starts), plus two fixes in the panel. If you aren't testing these changes, stay on [v0.5.0](https://github.com/yiw190/hibiki/releases/tag/v0.5.0).

### Fixed
- **The chat title now follows Gamut's renames.** A new chat used to keep its first message as its title even after Gamut renamed it. The panel now re-reads the name when Gamut sends `session_updated`, and checks again 2 s and 12 s after each reply as a fallback.
- **Recent chats use the panel's LED bar.** The `●` marker is replaced with the same LED bar as the Context button: blue while a chat is running, grey otherwise.
