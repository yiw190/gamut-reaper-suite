**Dev build for testing, not a stable release.** It includes everything in [0.5.1-dev.2](https://github.com/yiw190/hibiki/releases/tag/v0.5.1-dev.2) plus one panel change. If you aren't testing these changes, stay on [v0.5.0](https://github.com/yiw190/hibiki/releases/tag/v0.5.0).

### Changed
- **Tool line:** the line under a reply now lists only the tools that ran, e.g. `>_ Bash ×7`. The blue "N calls" total is gone because it repeated the per-tool counts. Hovering still shows the order the calls ran in when a reply used more than one tool.
