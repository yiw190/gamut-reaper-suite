**Release candidate 1 for 0.6.0: version history, a playback meter, audition racks, Ears and shared agent rules.** Everything from v0.5.1-rc.1, plus the changes below.

### Install
Install `Hibiki-0.6.0-rc.1.pkg` (macOS) or `Hibiki-0.6.0-rc.1-setup.exe` (Windows) over v0.5.x, then restart REAPER so the new bridge, panel and meter load. `hibiki doctor` should show `0.6.0-rc.1`. Installing a package switches the machine back to release mode.

### New
- **Version history** (Agent settings, left column):
  - After every agent reply that changed the project, a copy of it is kept in `<project folder>/.hibiki/history/` (the project as it was, saved or not; about 40 KB each, no audio, the newest 200 kept).
  - Each version is titled with the reply's own first sentence, and the tooltip lists what changed.
  - The top row is **Current**, with **Save version** when it isn't in the history yet. Each version shows its time to the second and a **Go to** button, which saves Current as a version first and then makes the tab that version. Every move can be undone from the same list.
  - The bridge records what changed: every request that can change the project is one undo point labelled `Hibiki <reply>: <what changed>`, and a `batch` is one point. For `run_lua` and raw API calls it compares the project before and after (tracks, volume, pan, mute, FX added / removed / bypassed / offline, items, lanes, sends, tempo). A `-- comment` on the script's first line becomes its title.
- **Measure playback** (Agent settings → Context): `Hibiki_Meter.jsfx` on the master's monitoring FX measures what you play. It never renders and doesn't touch the sound.
  - Measured values: LUFS-M/S (BS.1770), 4× true peak, correlation, side vs mid and eight bands.
  - The next message's context carries the last playback: gated LUFS-I, loudest LUFS-S and true peak with their bar.beat, correlation minimum, band levels and a per-bar row.
  - REAPER's menu bar shows "monitor FX" while it's on.
- **Audition rack** for comparing audible alternatives: sounds, parts, arrangements, effects. Racks aren't meant for levels, because a few dB is hard to hear by switching.
  - An agent puts each variant on a lane of one track (REAPER 7 fixed lanes, tagged `P_EXT:hibiki_lanes`); tagged variant tracks or FX also work.
  - The panel shows `Group [1][2][3]  <playing variant>  Keep N`.
  - A click (or keys 1–9) switches without an undo point. When the transport is stopped, the click also loops the time selection, so a click is a listen.
  - **Keep N** deletes the other variants in one undo step.
- **Ears**: with a time selection or razor area, **Ears** renders it from the master (up to 30 s), measures it and attaches the result to your next message as one chip (spectrum picture, summary, WAV). Removing the chip drops its numbers too.
  - REAPER supplies LUFS-I, LUFS-S max and true peak.
  - The new `hibiki ears <wav>` (stdlib only) adds 1/3-octave mid and side bands, tilt, the bands over and under it, stereo and level over time.
- **Agent rules**: `/remember <rule>` saves a line to `~/.config/hibiki/brain/rules.md`.
  - Before each chat with Codex, Claude Code, Kimi or Gemini, the gateway writes those rules, after a short block of panel conventions, into `AGENTS.md`, `CLAUDE.md` and `GEMINI.md` in the agents' working folder. It is a marked block; your own text in those files stays.
  - Agent settings → Context → Agent rules shows the count and opens the file.

### Changed
- **No drawn icons left**: the header's buttons read **Chats**, **New** and **Stop** (Stop only while a reply runs), and the tool line has no `>_` glyph.
- **Agent settings** layout:
  - Left column: Provider and Version history.
  - Right column: Context (with Measure playback and Agent rules), then one Hibiki box with version, updates and Recover.
  - Every on/off is a REAPER checkbox. "Include dev builds" is now "Include release candidates".
- **Wording**: one vocabulary throughout, sentence case, tooltips hold data only, and no ticking ages (recent chats show HH:MM or MM-DD).
- **Buttons and cards**: composer buttons, rack numbers and pills share one height. Disabled buttons dim. Card buttons have a visible face. A permission with no options says Deny.
- In dev mode, the panel's CLI calls (Recover, updates, Ears) go to the checkout, so an older installed `hibiki` no longer answers "exit 2".

### Fixed
- Text in Agent settings wraps inside its box (Recover's results ran out of it).
- Ears could stay on "Ears…"; it now times out after 90 s and still attaches the audio.
- A reply interrupted by switching chats kept its changes untitled.
- Panel tests on a Windows host (UTF-8 reads, paths).

### Known
- Apple's `DLSMusicDevice` crashes playback when more than one instance runs in a project. Keep one, or set the others offline.
- Signing and notarization of the installers are still to come.

### Upgrading
Install over v0.5.x. If you were in dev mode, the installer switches you back to this release.
